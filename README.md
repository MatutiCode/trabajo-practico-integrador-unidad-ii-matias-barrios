# Trabajo Práctico Integrador II - Sitio Web del IPF

**Materia:** Taller de Lenguaje de Programación I
**Año:** 2026
**Nombre Completo:** Matias Barrios Benjamin

## Descripción

Sitio Web del Instituto Politécnico de Formosa. Cuenta con una página de inicio con bienvenida, una seccion institucional con la historia del instituto y sus autoridades, una sección de carreras con descripción de cada una, y una sección de contacto.

## Tecnologías utilizadas

- HTML
- CSS
- Bootstrap
